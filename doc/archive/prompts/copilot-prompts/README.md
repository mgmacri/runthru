# Historical Prompt Archive

Prompt files in this directory are historical execution assets. They are useful
when the user explicitly asks to rerun, audit, or inspect the named milestone or
step, but they are not the active product roadmap or design direction.

For current UI/design work, agents must use
`doc/specs/active/design-direction.md` and the user's current designer-approved
brief before applying older prompt requirements. Legacy prompt rules about
blanket tokenization, shell/stage surface worlds, neumorphic-only loading, or
Material-default removal must not block current designer-directed UI unless the
current task explicitly opts into those rules.
